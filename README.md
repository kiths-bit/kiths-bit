## 🚀 Featured Projects

<details>
<summary><b>🛡️ ThreatLens — URL/Domain/IP Threat Intelligence & Risk Scoring Platform</b></summary>
<br/>

A full-stack cybersecurity tool that ingests a URL, domain, or IP and returns a composite risk score by combining lexical URL analysis, WHOIS/DNS/SSL enrichment, and reputation heuristics — built as a portfolio-grade, production-shaped security utility.

| Category | Details |
|---|---|
| **Stack** | Python, Flask, HTML/CSS/JS, Kali Linux |
| **Scale** | Single-service app, modular analyzer pipeline (lexical → WHOIS → DNS → SSL → scoring) |
| **Performance** | Lightweight synchronous enrichment pipeline, optimized for clarity over throughput |
| **Security** | Input validation, isolated dev environment outside `/root`, no hardcoded secrets |
| **Impact** | Demonstrates end-to-end threat-intel workflow design for a security engineering portfolio |


Built incrementally and deliberately — starting from a Flask skeleton, then layering input-type detection, URL lexical analysis, and enrichment modules (WHOIS, DNS, SSL) before arriving at a final weighted risk score and reporting layer.

</details>
